KOOLER — PGROWTH EVENTS
========================

Ficheiros:
- index.html        -> página do convite digital
- convite-kooler.png -> imagem enviada para o convite
- supabase.sql      -> tabela e política inicial do RSVP

NO ACODE:
1. Crie uma pasta chamada "kooler".
2. Coloque index.html e convite-kooler.png na mesma pasta.
3. Abra index.html no Acode.
4. No código, procure:
   SUPABASE_URL
   SUPABASE_ANON_KEY
5. Substitua pelos dados do seu projeto Supabase.

NO SUPABASE:
1. Abra o SQL Editor.
2. Cole o conteúdo de supabase.sql.
3. Execute.
4. Depois copie a URL e a chave pública do projeto para o index.html.

NÃO COLOQUE A SERVICE_ROLE KEY NO HTML.
